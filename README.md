# 永捷租賃電話詢價與多品項報價 v1.1.1

以電話接單順序記錄需求，再加入設備、軟體、網路工程、收送、急件及特殊人工品項。

## 公司規則

- 所有租賃包含維修及耗材；送裝與回收另外計費。
- 租期1天至3年。已有月租價不自動換算成新日租價，也沒有自動長約或大量折扣。
- 保留原20個設備方案、原計價方式與押金參考、800元／次運送及網路驅動設定。原雷射／噴墨50張為整段租期每台內含張數，噴墨超印費保留整元捨去。點陣每日100張，超量另約。
- 買碳免買機保留原耗材採購方案，每台每色1,500元，不列入租金優惠。

## 員工操作

1. 記錄客戶、用途、起迄日期、最晚安裝完成時間及現場條件。
2. 加入不同品項；每項填數量、計費期數、規格與服務範圍。日期不自動換算期數，輸出前逐項核對。
3. 半年填6個月、全年12個月。沒有原價的設備或特殊租期選人工報價；未知價格空白，明確免費才填0。
4. 軟體授權與安裝分列；設備租金與網路工程分列；送裝與回收另外列明，不重複收同一段工時。
5. 優惠只用一筆金額或折讓百分比，僅套用勾選設備的基本租金，不含超印或服務。填寫優惠原因。
6. 確認稅額、押金及付款／續租安排；完成人工核對後輸出。仍有待估時，文字與列印均標示草稿及待確認清單。
7. 保存只在此瀏覽器；JSON可下載及匯入。匯入與載入均取消最後人工核對，避免沿用舊確認。

頁首「操作說明」可隨時查看。本機保存、備份與輸出仍為草稿；只有使用員工帳號在團隊頁同步才上傳本張報價到共用資料庫。正式報價須主管核准，仍不會自動保留庫存。

## 開發與驗證

- 測試包含原價回歸、多品項、待估與零元、數值驗證、優惠範圍、稅額、押金、急件／送裝確認、日期／租期限制與備份格式。
- GitHub `JohnnyYang0726/equipment-rental-calculator` 的 `main` 分支連接現有 Vercel 正式專案 `equipment-rental-calculator`。

## 團隊操作（v1.1.0）

1. 頁首「團隊／主管核准」使用檢測／維修已開通的同一組帳號登入。
2. 主管／客服可同步目前報價、搜尋客戶或單號、確認載入後編輯。工程師／收送不開放租賃金額。
3. 共用清單每15秒更新；輸入內容按同步才上傳。後端重算原價，保留每版與異動紀錄，舊版本不能覆蓋新版本。
4. 主管查看最新版本明細，填寫原因後核准或退回。待估、缺少核對不可核准；內容改變後取消原核准。
5. 正式文字／可列印HTML由團隊頁輸出，每次向後端核對最新核准。一般詢價頁僅輸出草稿。
6. 主管於員工區保存姓名、電子郵件、角色及啟用狀態。新帳號的一次性開通連結私下交本人設定密碼；既有帳號直接登入。不自動寄信。三套系統共用員工名單。
7. 使用完登出此分頁。登入保存在分頁sessionStorage；本機另存草稿不會隨登出刪除，含客戶資料的電腦請依公司規定管理。

## 後端與維護

- 共用既有 Supabase 專案 buzcduwjeddaqwsrbwlf。租賃使用獨立資料表，不更動檢測／維修計價。
- `supabase/rental_workspace.sql` 記錄已套用的租賃結構與核准RPC。RLS限制團隊及角色；禁止直接修改表格，透過經檢查的RPC寫入。
- `supabase/functions/team-onboard/index.ts` 為共用開通函式；此次只增加租賃正式網域的CORS，保留既有開通頁與主管驗證。
- `src/rental-database.test.ts` 使用隔離PGlite與原有權限結構測試；不操作正式資料。
- 價目表變更時先改原方案並更新伺服器價目表，評估priceVersion與既有核准版本；不可只改前端造成不同計價。
